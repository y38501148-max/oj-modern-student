# 0.1.0 验证记录

日期：2026-10-22。

## 自动化检查

`npm run check` 检查 JavaScript 语法、manifest 引用资源，并执行 12 项测试：

- 学生站地址识别及管理端排除。
- 版本比较、固定版本请求、凭证隔离、检查缓存及离线错误。
- 三项功能开关、更新提醒及稍后选择。
- 中英文样例标题识别，复制时保留样例空格、制表符和换行。
- Markdown 中的公式、图片、表格、代码块和界面控件过滤。
- 题面动态替换后重新挂载复制按钮。
- 原提交表单保留、Tab / Shift+Tab、输入事件及编辑工具栏重复初始化回归。
- Edge / GitHub 构建的更新检查行为。

`npm run package` 生成两份 ZIP；Edge 包的 manifest 位于 ZIP 根目录，GitHub 包可直接解压加载。
