# OJ Modern Student 隐私政策

生效日期：2026 年 10 月 22 日。

OJ Modern Student 为北航 Accoding 学生页面提供界面美化、样例复制、提交界面优化。

## 页面数据

扩展在当前页面本地处理题面、样例及用户正在编辑的代码。扩展不上传或建立账号、Cookie、源码、题面及提交记录数据库，不提供遥测或广告。

复制按钮仅在用户点击时向系统剪贴板写入对应内容。扩展不会读取系统剪贴板。用户提交代码时，扩展沿用原站提交接口，将代码和语言发送至 Accoding，随后查询评测状态。

## 本地存储

扩展本地存储只保存功能开关、版本检查结果及已推迟的更新版本。这些数据不在设备之间同步；卸载扩展会移除扩展本地设置。

## 权限用途

- `storage`：保存功能设置及版本状态。
- `alarms`：定时检查版本。
- `clipboardWrite`：点击复制按钮时写入剪贴板。
- 学生站内容脚本：读取和调整当前页面的显示内容。
- `raw.githubusercontent.com` 主机权限：读取下述固定的公开版本文件。

## 网络请求

比赛页通过原站接口读取提交分数；普通题目页按当前用户查询本题提交记录，并按用户 ID 筛选展示。等待评测的记录每 3 秒查询一次状态，评测完成后停止查询，页面隐藏时暂停。这些请求使用原站登录状态，记录仅用于当前页面。

扩展会每 6 小时或在用户手动检查时请求以下公开文件：

`https://raw.githubusercontent.com/y38501148-max/oj-modern-student/main/version.json`

该请求不包含 OJ 账号、Cookie、页面内容或代码，不附带身份凭证。GitHub 作为网络服务方可接收 IP 地址和常规 HTTP 请求信息，适用其隐私政策。扩展的 Edge 商店更新另由浏览器及商店处理。

点击 GitHub、下载更新或打开 OJ 等链接，会打开对应网站，适用该网站自己的隐私政策。

## 联系与变更

问题可通过 [GitHub Issues](https://github.com/y38501148-max/oj-modern-student/issues) 提出。请勿在公开 Issue 中上传学号、Cookie、未公开题面或私人代码。隐私政策的变更随仓库版本发布。
